# Viviendas con Pascal

Recorrido de la arquitectura real de ambas viviendas, derivado del modelo Blender del 8 de octubre de 2026. [Abrir recorrido](https://corvusdevs.github.io/viviendas-pascal/).

Elegí una vivienda y pulsá **Entrar a la vivienda**. En escritorio: WASD o flechas, clic o arrastre para mirar y Esc para salir. En móvil: control Caminar y arrastre de la vista. **Ver planta** pausa el recorrido y muestra una planta derivada de las paredes y pisos reales; Esc la cierra y devuelve el foco al botón.

Esta versión ligera conserva la distribución y la escala, con puertas abiertas, materiales simples y muebles de terceros omitidos. No reproduce el acabado fotográfico del archivo de Blender ni sustituye un plano ejecutivo. El GLB visual pesa 2,25 MB y el de colisiones 2,24 MB. Los archivos 3D públicos se pueden descargar.
